# 비움 (BIUM) — 수원역 로데오거리 QR 쓰레기통 환경마일리지 앱

> 버리는 손이, 돌려받는 손으로.

"지역문제의 창의적 해결" 아이시스 1조의 중간·기말 발표용 **고충실도 프로토타입**입니다.
백엔드 없이 브라우저만으로 전부 동작하고, 상태는 이 브라우저의 `localStorage`에 저장됩니다.

## 실행 방법

| 방법 | 설명 |
| --- | --- |
| 파일 더블클릭 | `index.html`을 열면 바로 실행돼요. 글꼴(Pretendard)만 인터넷에서 받아요. |
| 로컬 서버 | 이 폴더에서 `npx serve` 실행 후 안내된 주소로 접속해요. `overview.html`의 iframe 미리보기는 서버로 여는 쪽이 안정적이에요. |

- 데스크톱 브라우저에서는 390×844 폰 프레임 안에 렌더되고, 뷰포트 폭 480px 이하(실제 폰)에서는 전체 화면으로 열려요.
- `overview.html`을 열면 주요 화면 23개를 가로로 한 번에 볼 수 있어요. 발표 슬라이드 캡처용이에요.

## 발표 시연 순서 추천

1. `index.html` 열기 → 온보딩 3장 → 홈
2. 홈에서 가운데 QR 스캔 버튼 → "QR 인식 시뮬레이션" → 재활용 선택 → 300원 결제 → 카운트다운 → "다 버렸어요" → 300P 환급 완료
3. 스토어에서 텀블러 교환 → 내정보 교환함에서 바코드 확인
4. 지도에서 가득 찬 핀(RD-04) 탭 → 내정보 맨 아래 "운영자 모드"로 수거 권장 순서와 시간대별 차트 보여주기

잔액 부족 흐름을 보여주려면 지갑 잔액이 300원 밑으로 내려갈 때까지 비움을 반복하거나, `index.html?state=scan-pay-short`로 열면 돼요.

## 데이터 초기화

- 앱 안: 내정보 → 설정 → 데이터 초기화 → 확인. 거래 내역·마일리지·교환함이 시연용 초기값으로 돌아가고 온보딩이 다시 나와요.
- 브라우저 콘솔: `BIUM.reset()` 후 새로고침.
- 저장 키는 모두 `bium.` 접두사를 써요(`bium.state`).

초기값: 지갑 4,700원 · 마일리지 6,420P · 거래 20건(오늘 기준 10일 전부터) · 교환함 2개(실리콘 빨대 세트, 로데오분식 쿠폰).
거래 날짜는 "오늘"에서 역산해 만들어서, 발표 날짜가 바뀌어도 최근 내역으로 보여요.

## 미리보기 상태 쿼리

`index.html?state=이름`으로 열면 특정 화면·상태를 바로 보여줘요. 이 모드에서는 저장소에 아무것도 쓰지 않아요.

`onboard1` `onboard2` `onboard3` `home` `map` `map-list` `map-sheet` `scan-camera` `scan-result` `scan-pay` `scan-pay-short` `scan-open` `scan-done` `wallet` `wallet-topup` `store` `store-suwon` `store-coupons` `store-sheet` `me` `me-empty` `report` `settings` `admin`

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 앱 셸(폰 프레임, 상태바, 탭바 자리) |
| `styles.css` | 디자인 토큰, 공통 컴포넌트, 화면별 스타일 |
| `app.js` | 해시 라우터, 상태 저장, 화면 렌더 함수, 스캔 상태 머신 |
| `data.js` | 쓰레기통 8개, 상품 12개, 거래 20건, 시간대별 투입 24개 값 |
| `icons.js` | 인라인 SVG 선 아이콘(1.75px stroke) |
| `overview.html` | 전 화면 가로 나열 발표용 페이지 |

외부 의존성은 Pretendard 글꼴 CSS 하나뿐이에요. 빌드 도구는 없어요.

## 점검

```
node -e "['data.js','icons.js','app.js'].forEach(f=>new Function(require('fs').readFileSync(f,'utf8')))"
```

위 명령으로 JS 문법을 검사했어요. 상위 폴더의 `_qa/test.js`는 Node용 미니 DOM 위에서 온보딩 → 스캔·결제·카운트다운 → 충전 복귀 → 교환 → 신고 → 초기화 → 미리보기 상태 16종까지 73개 항목을 자동으로 확인해요(`node ../_qa/test.js`). 실제 브라우저에서는 개발자 도구 콘솔을 열고 한 바퀴 돌아보면 돼요.
